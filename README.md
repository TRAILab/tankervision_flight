# tankervision_flight
Dev Location for the tankervision flight software 


## camera viewer node controls
Recommended viewer controls
For example:
e / E: exposure down / up
g / G: gain down / up
a: toggle exposure auto Off/Continuous
z: toggle gain auto Off/Continuous
b / B: target brightness down / up
m: cycle exposure algorithm Mean/Median
d / D: damping down / up
f: toggle frame-rate control
[ / ]: frame rate down / up
o: toggle AOI enable
arrows: move AOI
+ / -: scale AOI
p: print current settings
